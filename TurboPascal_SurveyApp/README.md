# Console Survey Application (Turbo Pascal)

A classic console-based interactive survey application built using **Turbo Pascal** and the **Turbo Vision** object-oriented UI framework.

### Features
- Interactive console GUI with menus and dialog windows
- Multiple-choice questions handling using radio buttons
- Session saving and result aggregation
- Simple and lightweight execution (requires DOSBox or compatible environment)
