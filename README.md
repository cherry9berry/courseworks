# CourseWorks

A collection of various standalone academic assignments covering fundamental algorithms, GUI development in legacy frameworks, assembly-level cryptography, and peer-to-peer networking.

---

Сборник различных обособленных учебных заданий, охватывающих базовые алгоритмы, разработку GUI в устаревших фреймворках, криптографию на уровне ассемблера и одноранговые P2P сети.
