# Infix to Postfix Converter (Pascal)

A simple academic project developed in Pascal ABC. It implements Edsger Dijkstra's **Shunting-yard algorithm** to convert standard infix mathematical expressions into Reverse Polish Notation (RPN / Postfix). 

### Features
- Stack implementation using native string manipulation
- Support for basic arithmetic operations (`+`, `-`, `*`, `/`, `^`)
- Parenthesis handling
- Step-by-step console visualization of the conversion process
